## What is YAML?

YAML (YAML Ain't Markup Language) is a human-readable data-serialization language. It is commonly used for configuration files and in applications where data is being stored or transmitted. YAML targets many of the same communications applications as Extensible Markup Language (XML) but has a minimal syntax which intentionally differs from SGML.

## YAML vs JSON

While JSON is perfect for APIs and data transmission due to its strict structure, YAML is often preferred for configuration files (like Docker Compose, GitHub Actions, or Kubernetes manifests) because it is much easier for humans to read and write. It allows comments and uses indentation rather than brackets and braces.

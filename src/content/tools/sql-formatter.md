## What is an SQL Formatter?

An SQL formatter is a developer utility that takes poorly spaced, minified, or disorganized SQL code and applies standard indentation, line breaks, and capitalization rules. This makes complex `JOIN`s, subqueries, and `WHERE` clauses significantly easier to read and debug.

## How to use this tool

1. Select your specific SQL dialect from the dropdown menu (e.g., PostgreSQL, MySQL, Standard SQL). 
2. Paste your raw, unformatted query into the left editor box.
3. The right box will instantly display the beautifully formatted query, automatically capitalizing keywords (like `SELECT` and `FROM`) and indenting nested subqueries.
4. Click the copy icon to copy the formatted code.

All processing is done completely locally using JavaScript. Your queries and database schema structures are never uploaded to any servers.

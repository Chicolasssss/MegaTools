## Understanding HTTP Status Codes

When you visit a website, your browser sends a request to the server. The server responds with a three-digit HTTP status code. These codes are divided into five categories:

- **1xx (Informational):** The request was received, continuing process.
- **2xx (Successful):** The request was successfully received, understood, and accepted.
- **3xx (Redirection):** Further action needs to be taken in order to complete the request.
- **4xx (Client Error):** The request contains bad syntax or cannot be fulfilled.
- **5xx (Server Error):** The server failed to fulfill an apparently valid request.

## Common Uses
Use this reference tool when debugging API responses, setting up NGINX/Apache redirects, or auditing your website for SEO (e.g., checking for 404 Not Found errors or 301 Permanent Redirects).

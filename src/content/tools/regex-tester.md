## What is a Regular Expression (Regex)?

A Regular Expression (or Regex) is a sequence of characters that specifies a search pattern. Usually such patterns are used by string-searching algorithms for "find" or "find and replace" operations on strings, or for input validation (e.g., checking if an email is valid).

## How to use this tester
1. Enter your pattern in the top input box (between the `/` slashes).
2. Add any optional flags (like `g` for global search, or `i` for case-insensitive).
3. Type or paste your test text in the "Test String" box.
4. The tool will instantly highlight matching sequences.

*Note: This tool uses the JavaScript Regular Expression engine native to your browser. Your regex and text are evaluated entirely client-side.*
